# How to perform CRUD operations in Blazor Scheduler using OData Adaptor

This project demonstrates batch CRUD operations in the [Blazor Scheduler](https://www.syncfusion.com/scheduler-sdk/blazor-scheduler) using OData adaptor integration with .NET 10. It covers handling event data through Create, Read, Update, and Delete operations while leveraging the OData protocol for efficient data communication and synchronization. The sample serves as a practical reference for implementing scalable and enterprise-ready scheduling applications with Syncfusion Blazor components.

## Technologies

* **Blazor** - Modern web framework for building interactive web applications
* **.NET 10** - Latest .NET platform for building robust applications
* **Syncfusion Blazor Scheduler** - Enterprise-grade scheduling component
* **OData Adaptor** - Protocol for data access and manipulation

## Features

* Batch CRUD operations using OData adaptor
* Real-time event scheduling and management
* Integration with Syncfusion Blazor Scheduler
* Responsive design for multiple screen sizes
* Efficient data synchronization

## Prerequisites

- Visual Studio 2026 or Visual Studio Code
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)

## How to run the project

**Visual Studio 2026**:

* Checkout this project to a location in your disk.
* Open the project (`BlazorSchedulerCrud.csproj`) file.
* Restore the NuGet packages.
* Run the project.

**Visual Studio Code**:

* Open the repository folder in Visual Studio Code.
* Open the integrated terminal.
* Navigate to the repository root.

```bash
cd Blazor-Scheduler-CRUD-using-ODATA-adaptor
dotnet restore
dotnet run
```

Open the URL displayed in the terminal after the application starts.

## Configuration

Configure the OData service endpoint in your application settings to enable communication between the Blazor Scheduler and your backend data service. Ensure your OData service supports batch operations for optimal performance.
